## 列表切片
要点：
- 基本语法：`seq[start:stop:step]`，返回一个新的列表（切片不包含 stop 索引）。
- 常见用法：
  - `a[0:5]`：从索引 0 切到索引 5（不含）
  - `a[5:]`：从索引 5 到末尾
  - `a[:5]`：从开始到索引 5（不含）
  - `a[::2]`：步长为 2，取每隔一个元素
  - `a[::-1]`：反转列表

示例：
- a = [10,20,30,40,50,60]
- a[1::2] -> [20, 40, 60]
- a[::-1] -> [60,50,40,30,20,10]

常见陷阱：
- 切片返回的是浅拷贝（对可变元素的内部修改仍会影响原序列）。
- 负索引和超范围索引安全（不会抛异常），但理解边界很重要。

快速提示：
- 用切片快速复制列表：`b = a[:]`。

## 列表遍历（for）
要点：
- 直接遍历列表元素：`for item in a:`。
- 如果需要索引同时获取值，使用 `enumerate(a)`。

示例：
- for x in [10,20,30]: print(x)
- for i, v in enumerate(a): print(i, v)

常见陷阱：
- 在遍历时修改列表（增删元素）容易导致跳过元素或索引错误，建议遍历副本或使用列表推导式。

---

## 列表排序与随机化
要点：
- 就地排序：`a.sort()`（返回 None，改变原列表）
- 降序：`a.sort(reverse=True)`
- 新排序副本：`sorted(a)` 返回新列表
- 随机打乱：`random.shuffle(a)`（就地打乱）

示例：
- a = [50,40,30,20,10]
- a.sort() -> [10,20,30,40,50]
- random.shuffle(a) -> 元素顺序随机

常见陷阱：
- 记住 `sort()` 返回 None（直接在原列表上操作）；不要写 `a = a.sort()`。

## 元组（tuple）
要点：
- 元组用小括号 `()` 定义，是不可变序列。
- 支持索引与切片，但不支持原地修改元素。
- 常用作不可变数据集合，例如函数返回多个值时常用元组。

示例：
- a = (10,20,30)
- a[0] -> 10

常见陷阱：
- 试图赋值 `a[0] = 100` 会抛出 TypeError。

快速提示：
- 需要修改时，可将元组转换为列表修改后再转回：`tmp = list(a); tmp[0]=100; a = tuple(tmp)`。

## zip 函数
要点：
- `zip(iter1, iter2, ...)` ���并行将输入可迭代对象的元素打包为元组，返回一个可迭代的 zip 对象。
- 转为列表查看结果：`list(zip(a,b))`。
- zip 在最短输入耗尽时停止。

示例：
- a=[1,2,3]; b=['a','b','c']; list(zip(a,b)) -> [(1,'a'),(2,'b'),(3,'c')]

常见陷阱：
- zip 对象是一次性迭代的（在 Python 3 中），若想重复使用需转换为列表。

## 列表推导式与类型转换
要点：
- 列表推导式格式：`[expr for var in iterable if cond]`。
- 用途：构造/过滤/映射序列，通常比显式循环更简洁。
- 列表和元组可以相互转换：`tuple(list)` 或 `list(tuple)`。

示例：
- a = [x*3 for x in range(10)]
- tuple(a) 将结果转换为元组

快速提示：
- 对复杂表达式或多重循环，适度使用推导式，避免可读性下降。

## 字典（dict）的创建方式
要点：
- 常见创建方式：字面量、`dict()` 构造、列表/元组对构造、zip 构造。

示例：
- a = {'name':'Alice','age':30,'city':'New York'}
- b = dict(name='Bob', age=25, city='Los Angeles')
- c = dict([('name','Charlie'),('age',35)])
- d = dict(zip(['name','age'], ['David', 40]))

常见陷阱：
- 使用 `dict()` 时，键必须是合法的标识符（当使用关键字参数形式），否则使用字面量或 `zip`。

## 字典访问、增删改查
要点：
- 访问：`a['name']`（键不存在会抛 KeyError）或 `a.get('name')`（返回 None）
- 设置/修改：`a['city'] = 'Los Angeles'`
- 删除：`del a['age']` 或 `a.pop('age', default)`
- 查看项：`a.items()`, `a.keys()`, `a.values()`

示例：
- a.get('country', 'USA') -> 当键不存在时返回默认值

常见陷阱：
- 直接用 `a['missing']` 若键不存在会抛异常，推荐使用 `get` 或先判断 `in`。

---

## 字典遍历（keys/values/items）
要点：
- 遍历键：`for k in a:` 或 `for k in a.keys():`
- 遍历值：`for v in a.values():`
- 遍历键值对：`for k, v in a.items():`

示例：
- for k, v in a.items(): print(k, v)

常见陷阱：
- 在遍历字典同时修改（增/删）会抛出 RuntimeError，若需修改请先收集要删除的键，再统一删除。

---

## 序列解包与注意点
要点：
- 序列解包可以把可迭代对象的元素依次赋值给多个变量：`x, y, z = seq`。
- 当对字典直接解包时（如 `a, b, c = s`），默认解包的是字典的键（iteration over dict yields keys）。

示例与陷阱：
- s = {'name':'Alice','age':30,'city':'New York'}; a, b, c = s  # a 是第一个键 'name'
- 如果需要键值对，使用 `for k, v in s.items():` 或解包 `list(s.items())`

快速提示：
- 解包长度必须匹配序列元素数量，否则抛 ValueError；可用 `*rest` 捕获剩余元素。

## 列表中存放字典并访问（常见数据结构模式）
要点：
- 将多个人/记录以字典形式放入列表是一种常见结构：`rows = [dict(...), dict(...)]`。
- 访问通常通过索引 + 字典键：`rows[i]['name']`。
- 也可用循环遍历：`for rec in rows: print(rec['name'])`。

示例：
- d=[{'name':'Alice','age':30},{'name':'Bob','age':25}]

# 修改为安全的代码示例块：
```python
# 列表中存放字典并访问的示例
d = [{'name':'Alice', 'age':30}, {'name':'Bob', 'age':25}]
for i in range(len(d)):
    # 使用 get 可以避免 KeyError，如果 age 缺失可以返回默认值
    print(d[i]['name'], d[i].get('age', 'N/A'))
```

常见陷阱：
- 假设所有字典都有相同键时要小心（使用 `get` 提防 KeyError）。
