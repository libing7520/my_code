## 变量与赋值
要点：
- 变量是名称-值的绑定；Python 中变量无需声明类型，赋值即创建。
- 常量常用大写命名（约定俗成，非语言强制）。
- 链式赋值：`a = b = c = 3`，三个名字同时指向同一对象（对于可变对象要注意副作用）。
- 解包赋值：`a, b = 1, 2`，可以用于交换：`a, b = b, a`（无需临时变量）。

示例：
- `PI = 3.14`
- `a, b = 1, 2` → `a, b = b, a`

常见陷阱：
- 对可变对象使用链式赋值会导致别名（aliasing）：修改其中一个会影响其它引用。

快速提示：
- 使用描述性变量名，常量用全大写以便于辨识。

## 数据类型
要点：
- 常见数值类型：`int`, `float`, `bool`, `complex`；文本类型：`str`。
- 用 `type()` 查看类型。
- 进制表示：二进制 `0b...`，八进制 `0o...`，十六进制 `0x...`。
- 类型转换：`int()`, `float()`, `str()` 等。

示例：
- `a = 5; b = float(a)`

常见陷阱：
- 布尔值 `True/False` 是 `bool`，但在数值运算中等价于 `1/0`。
- 大整数在某些实现细节上��会与小整数缓存相同对象（影响 `is` 判断）。

快速提示：
- 用 `is` 比较对象标识（同一对象），用 `==` 比较值相等。

## 运算符
分类与要点：
- 算术运算：`+ - * / // % **`。
- 比较运算：`== != > < >= <=`。
- 逻辑运算：`and`, `or`, `not`（短路行为）。
- 位运算：`& | ^ ~ << >>`（对整数位操作）。
- 身份运算：`is`, `is not`（判断是否是同一对象）。
- 成员运算：`in`, `not in`（检查元素是否在序列中）。
- 增量赋值：`+=`, `-=`, … 等���于就地更新（但对不可变对象会产生新对象）。

示例：
- `a // b` 整除；`a % b` 取模；`a ** b` 幂。
- 位运算示例：`5 & 3` → `1`。

常见陷阱：
- `/` 返回 `float`；若需要整除使用 `//`。
- 对可变对象使用 `+=` 可能会修改原对象（列表），对不可变对象则返回新对象（字符串）。

## 字符串（String）
要点：
- 字符串是不可变序列，支持索引与切片（slice）。
- 常用方法：`replace`, `split`, `join`, `center`, `rjust`, `format` 等。
- 字符串拼接使用 `+` 或 `str.join()`（拼接大量字符串时 `join` 更高效）。
- 格式化：`'My name is {} and I am {}.'.format(name, age)` 或 f-string（推荐 Python 3.6+）。
- `len()` 返回长度；`in` 检查子串。

示例：
- 切片：`s[0:5]`, `s[-1]`。
- `s.split()` 与 `'-'.join(list)`。
- `s.replace('r', '李')`。

常见陷阱：
- 字符串不可变，诸如 `s[0] = 'x'` 会报错；要构造新字符串。
- 索引越界会抛出异常；切片安全且会返回空序列而不是异常。

快速提示：
- 使用 `str.format()` 或 f-strings 进行更可读的格式化。

---

## 列表（List）
要点：
- 列表是可变序列，支持索引、切片、迭代与常用方法（`append`, `insert`, `extend`, `remove`, `pop`, `clear`）。
- 列表推导式是构造列表的常用简洁方式：`[x*2 for x in range(5)]`。
- 查找与统计方法：`index`, `count`。

示例：
- 添加：`a.append(80)`，`a.insert(1,30)`，`a.extend([60,70])`。
- 删除：`del a[0]`, `a.remove(30)`, `a.pop(1)`。

常见陷阱：
- `list.copy()` 或切片 `[:]` 用于浅拷贝；深拷贝需 `copy.deepcopy()`。
- 在遍历列表时删除元素可能导致跳过元素或索引问题，建议先复制或反向遍历。

---

## 时间与日期（time 模块）
要点：
- `time.time()` 返回 Unix 时间戳（秒）
- `time.localtime()` 返回本地时间的 struct_time 对象
- `time.strftime(format, time.localtime())` 格式化时间为字符串

示例：
- `time.strftime("%Y-%m-%d %H:%M:%S", time.localtime())`

常见陷阱：
- `time` 模块处理的是本地或者 UTC 时间戳与 struct_time，若要更方便地处理日期/时区建议使用 `datetime` 模块或第三方库 `pytz` / `zoneinfo`。

---

## 基础输入/输出：io.StringIO
要点：
- `io.StringIO` 提供一个在内存中的可变字符串缓冲区，适合做轻量级的文本读写模拟。
- 它支持 `seek()`, `write()`, `getvalue()` 等方法。

示例：
- 创建并写入：
  - `buf = io.StringIO('abcdefgh')`
  - `buf.seek(3); buf.write('xxx'); buf.getvalue()` → 返回修改后的字符串（注意这只是缓冲区内容）。

常见陷阱：
- `StringIO` 不是文件对象的完全替代，某些文件特性（如文件描述符）不可用。

## turtle 简单绘图与几何计算
要点：
- 通过简单坐标操作可以计算两点之间距离：distance = sqrt((x2-x1)**2 + (y2-y1)**2)
- `turtle` 模块用于教学与简单绘图，支持移动、抬笔、落笔等操作。

示例：
- 计算两点距离并用 `turtle` 绘制两点：
  - `turtle.penup(); turtle.goto(x1,y1); turtle.goto(x2,y2); turtle.pendown()`

常见注意：
- 在无图形环境（例如某些服务器或自动化测试）运行 `turtle` 会阻塞或出错；通常在本地带 GUI 的环境使用。
